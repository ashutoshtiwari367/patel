PATEL CONSTRUCTION - PREMIUM WEBSITE
=====================================

Files:
- index.html
- style.css
- script.js
- assets/

HOW TO RUN:
1. Extract the ZIP.
2. Open index.html in Chrome.
3. For XAMPP, copy the folder to:
   C:\xampp\htdocs\patel-construction\
4. Open:
   http://localhost/patel-construction/

NOTES:
- The design is responsive for desktop, tablet and mobile.
- Images currently use optimized Unsplash image URLs so the page can be viewed immediately.
- Replace the placeholder email in index.html with the company's real email.
- Replace project/client data with real information before publishing.
- Contact form is frontend-only. Connect it to PHP/Laravel/API for real enquiries.
